# Conceptualize Release Notes

## Version 0.1.0 - Features Overview

Conceptualize is an intelligent knowledge management tool that transforms your folder of Markdown notes into a living, interactive knowledge network.

### New Features in v0.1.0

#### Todo List Management
- **Inline Todo Blocks**: Create todos directly within your markdown notes using checkbox syntax
  - Example: `- [ ] Task name {priority: 1, start: 2025-01-15, end: 2025-01-20, desc: "Description"}`
- **Priority Levels**: Organize tasks with 4 priority levels (1=urgent, 2=high, 3=medium, 4=low)
- **Date Tracking**: Set start and end dates for tasks
- **Auto-sync**: Todos in notes automatically sync with the app's todo system
- **Task Archive**: Completed tasks are automatically archived
- **Multiple Lists**: Create custom todo lists with emojis and names
- **Linked Notes**: Connect todos to specific notes for better context

#### Timeline & Gantt View
- **Visual Timeline**: See all your tasks with dates on an interactive Gantt chart
- **Drag & Drop**: Reschedule tasks by dragging them on the timeline
- **Priority Colors**: Tasks are color-coded by priority (red, orange, yellow, white)
- **Date Ranges**: View tasks spanning multiple days
- **Today Marker**: Clear indicator showing the current date

#### Core Knowledge Management
- **Markdown Editor**: Rich markdown editing with formatting shortcuts
- **Wiki-links**: Connect notes using `[[note-name]]` syntax (Ctrl+Click to follow)
- **Graph View**: Visualize relationships between your notes
- **File Tree**: Organize notes in folders with drag & drop
- **Search**: Find notes by filename or content
- **Context Menu**: Quick actions (New Note, New Folder, Refresh, Reveal in Explorer)
- **Auto-save**: Your work is automatically saved

#### Technical Features
- **Local-First**: All data stays on your device
- **No Account Required**: Start using immediately without sign-up
- **Cross-platform**: Windows 10+ (x64) support
- **Fast & Lightweight**: Built with Tauri for optimal performance

### Getting Started

1. Download the installer from [GitHub Releases](https://github.com/IamJunnn/conceptualize/releases)
2. Run `conceptualize_0.1.0_x64-setup.exe`
3. Select your notes folder (or create a new one)
4. Start organizing your knowledge!
